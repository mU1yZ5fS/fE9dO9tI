## 2. 政治界面按钮：资格公式（政治.gd）

```
_tier_allows_negative(tier, pol):
    tier <= 3                                    # 第一~三层（前12名）
    or (pol.loyalty >= 700 and gamerule(5)==1)
    or gamerule(5)==2
_central_slot_allowed(pol,tier,pos):  !调查中 ∧ 未任该职 ∧ (tier<=2 ∨ 忠诚≥700∧rule5==1 ∨ rule5==2)
_regional_slot_allowed(pol,tier,pos): !调查中 ∧ 未任该职 ∧ (tier<=3 ∨ 同上)
tier 划分: 影响力降序 前3=一档 前7=二档 前12=三档 其余=四档（找不到回退一档）
```

## 5. 月结 `monthly_politics`（politician_system.gd:116-190）

1. 极左+政治挂帅者：文革(3)与毛堡垒(6)修正不同时在线 → 作风转硬汉
2. 调查推进：`investigator_index<7 则+1；≥7 下次清零并解除`（0..7 共 8 档）
3. 监视推进：days_surveillance 同上
4. 自动支持（==10）：budget−1, party_support−20, agents−5, 忠诚+50,
   `power += (1976−年)×5`（负值），`power += power/10`（无 abs）⚠️ 与手动支持公式不对称，原版如此
5. 自动打压（==10）：budget−1, party_support−20, agents−20, 忠诚−250 ⚠️（手动打压仅−50），
   `power −= (1976−年)×5`；power≥10 再 `power −= power/10`
6. 职位月度 power 加成：中央三职+20 / 首都+15 / 大区+10（取最大档不叠加）；
   无职按 traits[2]：贪污+4 / 病弱−20 / 谋士 +1+corruption/50 / 其它+1；
   年份>1977 起 `power += (1976−年)/2`
7. 贪腐(18)在职 → corruption+2
8. modifier[14]（1975 整风遗产）：改革派 power+10；自由派（非自由派系领袖）power+5
9. 尾部 fill_vacant_faction_leaders + sync_in_power_flags + notify_stats

## 6. 年结 `annual_politics`（politician_system.gd:194-238）

- 全体 age+1；在职 years_in_power+1；领袖独立体 age+1
- 仅毛逝后结算：
  - 老死线：托派 100；其余 `91+(槽位%4)`
  - 病弱标记线（病弱者跳过）：托派 90；改革派 `85+(槽位%4)`；其余 `80+(槽位%4)`
  - 毛保护(i==0) 豁免击杀
- 随后 plot_politics

## 7. 阴谋 `plot_politics`（politician_system.gd:244-316）

```
入场: 毛已逝 ∧ (目标power>250 ∨ gamerule(4)==1)
密谋势力 plot_power = Σ 入伙者.power
入伙谓词（遍历其他政客，排除空位/调查中/羞怯/病弱，按其对目标的矩阵值 rel）:
  谋士(16): rel<450   和平(9): rel<150   其它: rel<300
抵抗 resist = 3.0; 中华派(14)/偶像(13): 5.0; 傲慢(12)∨宽容作风: 2.0
  任总理 +2.0; 任军委 +1.0; 任外交 +1.0
触发: plot_power > resist × 目标power → is_conspiracy=true
三连随机（种子流）: rng.randf()*11 > 兵源/100 ∧ *22 > 兵源/50 ∧ *44 > 兵源/25
升级处置: plot_power > resist×4×power ∧ 击杀保护表:
  非中央三职 → kill_politician
  任中央职   → 清职(-1)，power=100（不置 you_fall）
否则（未过三连）: power −= power/10（不置 you_fall）
未触发: is_conspiracy=false
```

击杀保护表 `_plot_kill_allowed`（TimeScript.cs:331-335 对齐版，与按钮版略有差异——含 y1/y2 年份分支）。
