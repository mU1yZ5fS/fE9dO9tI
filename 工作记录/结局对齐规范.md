## 4. 文案与格式规则（最重要）
1. **逐字保留**原文字符串：包括字符间空格排版（`" 以 人 民 的 名 义"`）、`<color=#8B2323>`/`<size=54>`/`<color=red>` 等 Unity RichText 标签（Godot Label 开 BBCode 可渲染 `<color>`/`<size>`，主控负责开 bbcode_enabled）。不要把空格排版"优化"掉。
2. 源码字符串里的 `|` 是硬换行标记，**保留在返回 text 里**，由主控统一 `|` → `\n`（`||` 即空行）。
3. `text += "..."` 逐段按原顺序翻译；`string.Concat(new string[]{...})` 改为按顺序 `text += ...`（数组元素顺序不能变）。
4. `string.Format("{0}{1}...", a, b)` → `text += "%s..." % [a, b]`（GDScript `%` 格式化）；`{0}{1}` 姓名两参 → `_leader_name(w)` 单参（注释说明）。
5. `text = (text ?? "")` → GDScript String 不会为 null，忽略并注释。
6. 源码里的换行/`\n\n` 字面量 → 保留为 `"\n\n"`（GDScript 字符串转义照写）。
7. 双引号转义：原文字符串内半角 `"` 写 `\"`。中文引号 “ ” 无需转义。
8. 页面 title：`this.name.text = "..."` → 返回字典 `name` 字段。
9. 长字符串直接写在一行（项目现有规范），不要手动折行。
10. 每个 `_page_N` / `_ending_N` / `build_*` 函数头部注释标源码行号段，例如：
    `## 原作 EndingScript.cs L1049-1163（number_of_e==1，国家结构、思想观念与固有领土）。`
