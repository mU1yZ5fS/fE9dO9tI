## 输出格式
每个批次写一个文件：`F:\work\中国-毛的遗产[dh-4591]\场景\外交界面\外交互动_批X.gd`

文件骨架（严格 tab 缩进）：

```gdscript
## 外交互动 批X — 编号 A..B（源码出处见各函数注释）。
extends "res://场景/外交界面/外交互动_基础.gd"


## 主分发：返回 {caption, opis, conditions, effect, dormant} 或 {}。
func build_action(action_type: int, ctx: Dictionary) -> Dictionary:
	var w: WorldState = ctx.get("w")
	var darr: Array = ctx.get("d", [])
	var country: CountryData = ctx.get("country")
	var caption: String = ctx.get("caption", "")
	match action_type:
		N:
			return _def_N(w, country, caption)
	return {}
```

- `ctx["d"]` 是 `w.数值表`（同原版 data）。
- `ctx["caption"]` 是 CountryScript 分支给的按钮文案，**必须原样使用**，不得自造。
- 返回空 `{}` 表示该编号未定义（上层过滤不显示）。
- 所有 `_def_N` 中条件用 `cond("原版条件中文文案", Callable)`，效果用 `func(): ...` Callable。
- 禁止直接 `match` 里写大段 lambda 之外再定义顶层全局函数以外的局部命名冲突；每个编号独立 `_def_N`。

## 条件翻译规则（Show）
1. `number_uslovie` 决定显示前几项；Godot 侧把全部条件按原版顺序塞进数组即可（AND 全真才能点击，等价）。
2. `this.this_opis = "..."` → 返回的 `opis`（效果描述）。
3. `uslovie_text[i]` 保留原文案（原版带空格排版的中文也保留，如 `" 至 少 5 特 工 网 络"`）。
4. `uslovie_bool[i] = expr` 翻译成 `cond("文案", func(): return expr)`。
5. 原版对 `this.selected_country == N` → `country.原版序号 == N`。
6. `PlayerPrefs.GetInt("language") == 0` 分支已经限定，忽略俄文 else。
7. `GlobalScript.inst.dlc[3]` → `w.dlc.size() > 3 and w.dlc[3]`。
8. `GlobalScript.inst.gameState.data[i]` → `d(w, i)`；赋值用 `set_d(w, i, v)`。
9. `event_done[N]` → `ev(w, N)`；`resultOfEvents[N]` → `res(w, N)`。
10. `modifies[i].active` → `mod(w, i)`。
11. `ingamewars[i].is_going` → `war(w, i)`。
12. `war_active[i]` → `w.war_active[i]`（先判 `i < w.war_active.size()`）。
13. `empires[i].relations/power` → `rel(w,i)/power(w,i)`；`empires[i].now_leader` → `emp(w,i).current_leader`（先判非 null）。
14. `influencePRC` → `w.influence_prc`；`SOV_PRC_PartiesConnection` → `w.sov_prc_parties_connection`。
15. `leader.traits[x]` → 项目 `w.leader` 是 PoliticianData，字段为 `trait_personality/trait_alignment/trait_special/...`（见 `数据脚本/politician_data.gd`，以实际文件为准；查不到字段就保留 TODO 注释并返回不满足条件）。
16. 国家字段：
    - `Gosstroy` → `gov(c)`；`SubGosstroy` → `sub(c)`；`puppetOf` → `pup(c)`
    - `proprc/prosov/Vyshi/Torg/dota/usalliance/sovalliance` → `has(c, "亲中"/"亲苏"/"亲美"/"对华贸易"/"贸易同盟"/"美国盟友"/"苏联盟友")`
    - 联盟 `isNATO/isOVD/isSEV/isEcon/isASEAN/isSocEU/isFXSEU/isNAZIMAO/oar/okb/isRIM/isAU/isOil/isSENTO/isSEATO/isBALECON/isOLAS` → `has(c, "nato"/"ovd"/"sev"/"econ"/"asean"/"soc_eu"/"fxseu"/"nazimao"/"oar"/"okb"/"rim"/"au"/"oil"/"sento"/"seato"/"balecon"/"olas")`
    - `cw` → `c.内战中`；`perevorot` → `c.政变中`；`based` → `c.有驻军基地`；`africaOff` → `c.禁用非洲机制`
    - `stab` → `c.stab`；`soc_stab` → `c.social_stability`；`dev` → `c.development`
    - `sovpower/usapower/prcpower` → `c.sov_power/usa_power/prc_power`
    - `sovinfl/usainfl/prcinfl` → `c.sov_influence/usa_influence/prc_influence`
    - `inflCh/inflNATO` → `c.influence_china/influence_nato`
    - `level_of_dev/level_of_unstab` → `c.level_of_development/level_of_instability`
    - `parts[i]` → `parts(c, i)`；`spec` → `c.special`；`numberOfSpecialEnding` → `c.special_ending`
    - `next_elections.Year/Month/Day` → `c.next_election_year/month/day`
17. `IsSocialism(true,N)` → `soc(w, c(w,N), true)`；`IsSocialism(false,N)` → `soc(w, c(w,N), false)`；`IsAuthoritarianism(N)` → `auth(w, c(w,N))`。
18. `ChineseSubGosstroy()` → `chinese_sub_gosstroy(w)`；`AfricanSubGosstroy(g)` → `african_sub_gosstroy(w,g)`；`GetSubGosstory()` → `get_sub_gosstory(w)`。
19. `IsSocialism` 里直接给 `this.selected_country` 时用 `country` 对象即可。
20. 原版 `other_text[idx]` 文案：若现有 Godot 文件里已有等价常量/文案就复用；没有就在注释写 `TODO other_text[idx]`，文案用贴近原版的简体表达并注明行号，**不要编造业务含义**。本批次优先保证结构，文案可后续统一替换。

## 效果翻译规则（OnMouseDown）
1. 只翻译 `is_active` 条件通过后、对应 `if/else if (this.this_type == N)` 块内的语句，直到下一个同层 `else if`。
2. 数值运算逐行忠实翻译，保持整数除法语义（GDScript `/` 对 int 也是整数除法）。
3. `GameObject.Find`、`SceneManager.LoadScene`、`GlobalScript.inst.speed=0` 等 UI/场景切换：
   - `this.a.number_event = X; SceneManager.LoadScene("Event")` → `start_event("event_X")`（若项目没有该事件资源，注释 TODO）。
   - 其余场景切换（Diplomacy/Ending/Results 等）写 `GameManager.???` 前先查 `game_manager.gd`；没有对应 API 就注释 TODO，不硬造。
4. 直接 `event_done[N]=false` → `set_ev(w,N,false)`；`resultOfEvents[N]=x` → `set_res(w,N,x)`。
5. `allcountries[X].LeaveAlliances()` → `c(w,X).leave_alliances()`；`EstablishGovernment(Government.ProChina/ProSoviet/ProAmerican)` → `c(w,X).establish_government(2/1/0)`。
6. `allcountries[X].JoinAllOurAlliances(true)` → `join_all_our_alliances(w, c(w,X), true)`。
7. `allcountries[X].SubGosstroy = expr` → `c(w,X).sub_government = expr`；`Gosstroy` 同理。
8. `allcountries[X].dev += n` → `c(w,X).development += n`；`dev = n` → `c(w,X).development = n`。
9. `influencePRC += n` → `w.influence_prc += n`。
10. `war_active[i]=true` → `w.war_active[i] = true`（先确保数组长度，可用 `set_war_active` 自写小函数）。
11. `ingamewars[i].xxx=yyy` → `get_war` 辅助或按 WarData 字段逐项翻译；本项目 WarData 没有 `usa_place/ussr_place`，用 TODO 注释标明未建模。
12. `completedDecisions[i]` → 项目 DecisionState 查 `数据脚本/decision_state.gd`；没有对应 API 就注释 TODO 并跳过该行效果（不要静默删改其它效果）。
13. 效果执行后不要自己做 `clamp`（上层统一做）。
14. 对任何看不懂或无法映射的行：保留 TODO 注释并继续翻译其余行；在函数末尾统一写 `# TODO(批X,typeN) 未建模: ...`。
